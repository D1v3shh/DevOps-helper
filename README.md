# DevOps Helper

DevOps Helper is a Codex skill designed to teach DevOps concepts end-to-end using a standardized, highly effective 4-layer teaching format.

## Owner

Divesh  
GitHub: https://github.com/D1v3shh/

## What It Does

When you ask a DevOps-related question, this skill guides the agent to provide:

- 🧠 Concept explanation in plain language.
- 🏗️ Text-based architecture diagram illustrating the setup.
- 💻 Complete, working code or config examples.
- 📁 Recommended file and folder structure.

## Skill Files

- `SKILL.md`: The core system prompt and instruction set for the AI agent.
- `references/`: Detailed knowledge on specific DevOps topics like CI/CD, Cloud, Containers, Git, IaC, Kubernetes, Linux, and Monitoring.

## Example Use

Ask a question like "How does Kubernetes work?" or "Help me set up a GitHub Actions CI pipeline." The response should include a clear explanation, an architecture diagram, working code examples, and the required file structure.
